# KOL人驱动热点雷达（每6小时）

> 状态：ACTIVE  
> 数据窗口：每轮截止时间向前滚动 6 小时（可自定义）

## 1. 定位

本规则是独立自动化，不按八个赛道分组，不从赛道定向搜索出发。
起点只有一处：KOL list。

## 2. KOL list 范围

- 热点来源只有 KOL list 内的账号。
- 名单由用户自定义增删，分组标签仅作标注，不影响取数与展示。
- 每个账号必须记录：handle、分组标签（可选）、加入时间、是否启用。
- 名单外的账号即使 views 再高也不收录。

## 3. 发现顺序

固定执行：

- 不允许反过来先定主题再去搜账号，不允许先找热门市场再倒推该看谁。

具体步骤：

- 按 KOL list 逐个账号拉取最近 6（可自定义）小时新帖
- 不做赛道定向查询，不做关键词搜索
- 对候选逐条打开 X 直接状态页核验
- 先按 handle 归并去重
- 再按事件归并去重
- 按 views 从高到低排列
- 不要求匹配 Polymarket 市场
- 搜索页只用于发现，不能直接作为最终证据

## 4. 硬门槛

每条必须满足：

- 发布账号必须在 KOL list 内，且处于启用状态
- 发布时间严格位于本轮最近 6 小时窗口内
- 必须是直接状态链接：`https://x.com/<account>/status/<id>` 或 `https://twitter.com/<account>/status/<id>`
- 单条 views ≥ 10,000（门槛可自定义）
- 必须通过已登录浏览器或授权只读 X 数据层核验：
  - 完整正文
  - 精确发布时间
  - 公开 views
  - 点赞、转发、评论等公开互动
- 以下不能代替 X 原帖：
  - 搜索结果摘要
  - 账号主页
  - 话题页
  - 新闻截图
  - 转发截图
- 事实内容原则上必须有官方来源或可靠媒体佐证。
- 观点类内容必须明确保留“观点／预测”边界，不能当成已发生事实。

补充说明：

- `views ≥ 10,000` 是准入过滤条件，先过滤再排序。
- 如果业务侧调整门槛，默认由配置项控制，不写死在代码里。

## 5. views 规则

- 入榜后按实际 views 从高到低排序。
- 必须记录 X 页面实际整数。
- 不得估算、四舍五入，不得把“10K”“2.4M”直接当成精确整数。
- 确实不可见时写“views 未公开”，排在有实际 views 的帖子后面。
- views 相同时，依次比较：
  - 发布时间新近度
  - 点赞
  - 转发
  - 评论

## 6. 去重

单轮执行三层去重：

- X status ID：同一 X 原帖只出现一次
- handle：同一 handle 在同一 6 小时窗口内，只保留 views 最高的 1 条，其余一律丢弃，不占榜位
- 事件：标题不同但明显是同一事件，也只保留一条

事件归并建议按以下优先级判断：

- 同一主体
- 同一事实动作
- 时间窗口重叠
- 同一 X 原帖的转述/改标题版本

如果无法明确判定为同一事件，默认不合并。

执行顺序：

- 先按 handle 归并
- 再按事件归并
- 最后统一排序

冲突时：

- 优先保留 views 更高的帖子
- views 相同则保留发布时间更新的帖子
- 不得为了补满 Top 重新放回重复条目

多样性校验：

- 榜单至少覆盖 2 个不同 handle
- 窗口内只有 1 个 handle 达标时，照实展示 1 条，不拉低门槛凑数

## 7. 关于 Polymarket

- 本榜不要求“X 帖子 ＋ 相关市场”的交集。
- 不做相关盘筛选，不因找不到市场而剔除条目。
- 没有相关市场不影响入榜。
- 若帖子恰好有可解释的相关市场，作为附加信息展示：市场标题 ＋ 链接 ＋ 一句关联依据。
- 没有则写“本轮无相关市场”，不影响排名。

红线不变：

- Polymarket 有盘 ≠ 事件已发生
- 平台官方账号只确认平台自身行动
- views 高 ≠ 事情是真的

## 8. 排名与数量

- 全站一个榜，最多 Top 1–10
- 不按赛道分卡，不按分组拆分
- 排名第一标准：X 实际 views 从高到低
- 其次比较：发布时间新近度、点赞、转发、评论
- 不允许拿 Polymarket 自身成交热度替代 X 热度
- 不允许为凑满 Top 10 降低标准
- 只展示真实合格条目

## 9. 跨轮去重

跨轮还要读取由调度系统维护的 `memory.md`：

- 禁止把完全相同的帖子原样反复推送
- 同一事件只有出现新的合格 X 帖子、新官方进展或显著市场变化时才允许再次进入
- 连续两轮重复出现的帖子，若无可核验的新进展，不再展示

## 10. 卡片格式

- 推特内容
- 爆款公式

## 11. 空榜规则

- 卡片必须存在，但不要求强行有数据。
- 热门为空时只写一行缺口说明，不重复写 Top 1–10 空位。
- 推荐固定文案：`本轮暂无符合门槛的 KOL 热点帖。`

禁止：

- 重复输出 Top 1–10 空位
- 使用旧帖子填充
- 使用名单外账号补位
- 降低 views 门槛
- 用其他榜的内容补位
