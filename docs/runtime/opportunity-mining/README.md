# 热点挖掘规则包

本目录是热点挖掘 Agent 的默认规则包。规则包用于告诉总 Agent 如何从不同来源的 Signal 中判断是否存在运营机会、事件机会或内容洞察。

这些文档不是固定代码工作流。运营人员可以通过 AI 助手提出修改诉求，由 AI 助手生成新的 draft 规则包，测试通过后再激活。默认版本必须保留，便于回滚。

## 使用原则

- 业务判断写在 Markdown 规则文档里。
- 代码只负责加载规则、执行工具、记录审计、校验输出。
- 规则可以是自然语言，不要求全部变成固定字段。
- 规则变化后必须先短流程测试，再激活。
- 不确定时宁可请求人工复核，也不要编造事实。
