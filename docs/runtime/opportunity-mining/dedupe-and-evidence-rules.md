# 去重与证据规则

## 目的

避免同一机会重复创建，保证每个决策都有可追溯证据。

## 去重

在创建机会或事件前，应检查：

- 是否已有相同标题或高度相似标题的机会。
- 是否已有同一事实主体、同一动作、同一时间窗口的事件。
- 是否只是不同来源重复触发同一热点。
- 同一账号是否已经围绕类似角度生产过内容任务。

如果存在相似机会，优先输出 `update_existing_opportunity`。如果相似但不确定，应请求人工复核。

## 证据

- 创建机会、创建事件、更新机会必须引用 evidenceRefs。
- evidenceRefs 应引用具体 Evidence 或 Signal。
- 引用证据时必须保留不确定性。
- 数据缺失、接口失败、无法验证都要写入 missingData 或 riskNotes。
