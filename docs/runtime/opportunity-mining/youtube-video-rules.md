# YouTube 爆款视频挖掘规则

## 目的

用于判断 YouTube 视频 Signal 和字幕拆解结果是否值得形成内容洞察、选题机会或产品承接机会。

## 关注对象

- 视频标题、频道、发布时间和统计数据。
- 字幕中反复出现的核心论点。
- 视频结构、开头钩子、叙事推进和结论。
- 评论或外部讨论是否显示该视频正在扩散。

## 判断倾向

倾向形成洞察：

- 视频围绕明确问题展开，且结构可复用。
- 字幕显示出清晰的故事线、争议点或方法论。
- 视频主题与目标产品、行业趋势或用户痛点相关。
- 可以总结出可复刻的内容角度。

倾向忽略：

- 只有娱乐性观看价值，难以转化为运营选题。
- 字幕缺失且没有足够其他证据。
- 视频主题与当前产品或账号定位关系弱。

## 输出要求

如果形成机会，需要说明：

- 视频为什么可能火。
- 可复用的表达结构。
- 可以如何结合自身产品。
- 缺少哪些平台内部数据，例如完播率、留存或流量来源。
