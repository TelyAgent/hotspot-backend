# 全局判断原则

## 目的

适用于所有来源的 Signal。用于约束热点挖掘 Agent 的基本判断方式。

## 事实边界

- 只能基于 Signal、Evidence、工具返回结果和规则文档做判断。
- 不能把热度、传闻或单个账号观点直接当成事实。
- 如果事实来自二手转述，需要在风险说明里标注。
- 如果关键信息无法确认，应输出 `request_human_review` 或 `ignore`。

## 机会判断

形成机会时至少需要说明：

- 为什么现在值得关注。
- 为什么对目标用户或产品有意义。
- 可以从哪些角度承接。
- 当前内容窗口有多长。
- 哪些证据支撑这个判断。

## 人工复核

以下情况倾向请求人工复核：

- 证据互相矛盾。
- 来源可信度不足。
- 涉及政治、金融、医疗、法律等高风险内容。
- 可能伤害品牌安全。
- 需要产品、合规或运营负责人判断。
