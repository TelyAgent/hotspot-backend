# 未来事件挖掘规则

## 目的

用于判断未来事件 Signal 是否值得提前监控、预热或形成运营机会。

## 关注对象

- 事件时间、来源可信度和事件类型。
- 事件前、中、后的不同关注点。
- 预热窗口是否足够。
- 事件可能影响的行业、人群、市场或产品场景。
- 当前是否已经出现相关讨论或预期。

## 判断倾向

倾向形成机会：

- 事件时间明确，且距离当前仍有准备窗口。
- 事件可能引发搜索、讨论、市场波动或行业关注。
- 可以提前准备内容角度、数据看板或解读框架。
- 与目标产品、账号定位或用户决策相关。

倾向请求人工复核：

- 事件重要但时间、来源或影响范围不确定。
- 需要决定是否投入运营资源。
- 存在合规、金融、政治等高风险表达。

倾向忽略：

- 事件过于遥远且没有明确承接方式。
- 事件已过主要传播窗口。
- 缺少可信来源。
