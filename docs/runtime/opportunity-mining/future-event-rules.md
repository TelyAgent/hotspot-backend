# 未来事件挖掘规则

## 目的

用于判断未来事件 Signal 是否值得提前监控、预热，以及在达到最新触发规则时进入统一 Event 层。

进入 Event 的主规则以 `hotspot-source-event-trigger-rules-v2.md` 为准；旧未来事件专项规则只作为 Action Score、热力追踪、窗口和字段细节的依据。

## 关注对象

- 事件时间、来源可信度和事件类型。
- 事件前、中、后的不同关注点。
- 预热窗口是否足够。
- 事件可能影响的行业、人群、市场或产品场景。
- 当前是否已经出现相关讨论或预期。
- 当前 Action Score 是否达到 Event 门槛。

## Event 门槛

未来事件 Signal 不因为“来源可信、时间明确、还有准备窗口”直接形成 Hot Event。

只有满足以下条件时，才允许输出 `create_event` 或进入 Event 匹配：

```text
Action Score >= 80
```

低于 80 分的未来事件继续保留在 Future Event 池中，持续更新证据、时间、热度和评分，不独立创建热点 Event。

80 分只控制 Future Event 能否独立进入 Event 层，不提升事实确认状态，也不自动生成、发布或撤回内容。

## 判断倾向

倾向形成机会：

- Action Score 已达到 80 分。
- 事件可能引发搜索、讨论、市场波动或行业关注，并且已有热度、紧迫性或明确运营承接证据支撑。
- 可以提前准备内容角度、数据看板或解读框架。
- 与目标产品、账号定位或用户决策相关。

倾向请求人工复核：

- 事件重要但时间、来源或影响范围不确定。
- 需要决定是否投入运营资源。
- 存在合规、金融、政治等高风险表达。

倾向忽略：

- 事件过于遥远且没有明确承接方式。
- 普通远期官方日程、节假日或例行节点，Action Score 低于 80 分。
- 事件已过主要传播窗口。
- 缺少可信来源。

## 标签

达到门槛并进入 Event 时，应添加：

- `Future Event`
- `Action Score 80+`
- `Upcoming`
- `Official Schedule`（当证据来自官方日程来源）
