# 主题追踪挖掘规则

## 目的

用于判断重点主题下的账号帖子、主题候选和讨论聚类是否值得形成机会。

## 关注对象

- 主题候选的标题、摘要、关键词和实体。
- 参与讨论的账号类型和影响力。
- 讨论是否从单点扩散到多个账号或圈层。
- 讨论内容是否出现新的事实、观点冲突或产品承接角度。

## 判断倾向

以下任一规则命中，即倾向形成主题圈关注度触发。规则命中后仍需要检查事实依据、主题聚类质量和重复机会，不允许只凭指标直接编造事件。

## 主题圈触发规则

### TC-01：短期集中讨论

`B3h >= 3` 时，表示同一主题候选在最近 3 小时内出现集中讨论，倾向形成主题圈关注度触发。

需要证据：

- `TopicCandidate.metrics.b3h`
- 相关候选的 `representativeSignalIds`
- 候选摘要、关键词、实体和参与账号数量

输出倾向：

- 如果讨论指向同一具体事实或清晰问题，倾向 `create_opportunity` 或 `create_event`。
- 如果只是同一关键词下的多个不同事件，应请求人工复核。

### TC-02：24 小时持续热议

`B24h >= 6` 时，表示同一主题候选在 24 小时内持续被讨论，倾向形成主题圈关注度触发。

需要证据：

- `TopicCandidate.metrics.b24h`
- `firstSeenAt`、`lastSeenAt`
- 参与账号和帖子数量

输出倾向：

- 如果 24 小时内讨论持续且主题稳定，倾向形成机会。
- 如果讨论只是重复转述同一条低价值信息，应降低置信度或忽略。

### TC-03：单点流量爆发

`Tmax >= 3` 且该帖子进入账号近期表现前 5% 时，表示单条帖子可能带动主题关注度爆发。

需要证据：

- `TopicCandidate.metrics.tmax`
- `TopicCandidate.metrics.tmaxSignalId`
- 调用 `signal.getById` 读取 `tmaxSignalId` 对应帖子。
- 调用 `topicWatch.getAuthorPostPerformance` 检查该帖子是否进入作者近期表现前 5%。

输出倾向：

- 如果该帖子内容和主题候选一致，且进入账号近期前 5%，倾向形成机会。
- 如果缺少账号近期表现样本，输出 `request_human_review` 或降低置信度，并在 `missingData` 中说明缺少账号历史基准。

### TC-04：讨论与流量混合上升

`B3h >= 2` 且 `Tmax >= 2` 时，表示讨论数量和单点流量同时上升，倾向形成主题圈关注度触发。

需要证据：

- `TopicCandidate.metrics.b3h`
- `TopicCandidate.metrics.tmax`
- 代表帖子和参与账号

输出倾向：

- 如果讨论内容集中且代表帖子具有传播性，倾向形成机会。
- 如果指标命中但内容噪音高，应请求人工复核。

## 通用判断倾向

倾向形成机会：

- 多个相关账号在较短窗口内讨论同一事实或同一问题。
- 关键账号参与，使话题具有行业信号价值。
- 帖子中出现可引用事实、清晰观点或可复用选题角度。
- 该主题与产品定位、用户需求或行业变化相关。

倾向请求人工复核：

- 指标看起来升温，但帖子内容高度重复。
- 讨论来源过窄，可能只是单个账号带动。
- 涉及高风险判断，需要人工确认口径。

倾向忽略：

- 只有泛泛表达，没有新的事实或观点。
- 主题聚类不稳定，多个事件被混在一起。
- 无法找到可引用证据。

## 指标说明

- `B3h`：候选最近 3 小时内的相关帖子数。
- `B24h`：候选最近 24 小时内的相关帖子数。
- `Tmax`：候选代表帖子中的最高单点流量分数，首版按点赞、回复、转发、引用等公开互动量计算。
- `tmaxTop5Percent`：如果已有账号近期历史基准，可表示该帖子是否进入账号近期表现前 5%；缺失时应调用工具补充或请求人工复核。
