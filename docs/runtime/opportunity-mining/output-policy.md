# 输出策略

## 允许决策

- `create_opportunity`：形成新的运营机会。
- `create_event`：形成新的明确事件。
- `update_existing_opportunity`：更新已有机会。
- `create_insight`：只形成洞察，不进入事件。
- `ignore`：忽略。
- `request_human_review`：请求人工复核。

## 必填内容

最终输出必须包含：

- 中文标题。
- 中文摘要。
- 为什么现在值得做。
- 为什么重要。
- 产品承接角度。
- 内容窗口。
- 置信度。
- 证据引用。
- 缺失数据。
- 风险说明。

## 禁止行为

- 不要输出 Markdown。
- 不要编造数据。
- 不要把平台热度直接当事实。
- 不要在证据不足时强行创建机会。
- 不要把多个不相关事件合并成一个机会。
